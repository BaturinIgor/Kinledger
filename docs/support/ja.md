# Kinledger ヘルプ

## よくある質問

**iPhoneをなくしても記録は大丈夫ですか？**
クラウドバックアップがオンなら大丈夫です（自分 → バックアップ）。新しいiPhoneで同じAppleアカウントでサインインし、最初の画面で「復元」を選んでください。バックアップがない場合、記録はiPhoneにしかないため、オンにするか定期的に書き出してください。

**記録を誤って削除しました。**
「自分」→「ゴミ箱」を開いてください。記録は30日間保管されます。

**記録を変更しましたが、前のバージョンに戻したいです。**
記録を開いて「履歴」までスクロールし、戻したいバージョンをタップしてください。

**家族にもアプリが必要ですか？**
いいえ。月次レポートはPDFか、どのブラウザでも開ける非公開リンクで届きます。

**メモはレポートに含まれますか？**
共有する前に「非公開メモを含める」をオンにした場合のみ含まれます。

**Proを解約するには？**
iPhoneの設定 → ユーザ名 → サブスクリプション → Kinledger。解約後も記録と書き出しはそのまま使えます。

**すべてのデータを持ち出せますか？**
「自分」→「すべてのデータを書き出す」で、表とすべての領収書の写真をいつでも無料で書き出せます。
