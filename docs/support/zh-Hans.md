# Kinledger 帮助

## 常见问题

**如果手机丢了，我的记录安全吗？**
如果开启了云备份（我 → 备份），就是安全的。在新 iPhone 上用同一个 Apple 账户登录，并在第一个画面选择“恢复”。没有备份时，记录只保存在手机上，所以请开启备份或定期导出。

**我不小心删除了一条记录。**
打开“我”→“废纸篓”。记录会在那里保留 30 天。

**我修改了一条记录，想恢复旧版本。**
打开该记录并滚动到“历史”，轻点某个版本即可恢复。

**家人需要安装应用吗？**
不需要。他们会收到 PDF 格式的月度报告，或一个可在任何浏览器中打开的私密链接。

**我的备注会出现在报告里吗？**
只有在分享前开启“包含我的私密备注”时才会出现。

**如何取消 Pro？**
iPhone 设置 → 您的姓名 → 订阅 → Kinledger。取消后，记录和导出功能仍可使用。

**我能导出全部数据吗？**
我 → 导出我的全部数据：一份表格和全部收据照片，随时免费。
