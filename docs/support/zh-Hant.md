# Kinledger 說明

## 常見問題

**如果手機遺失，我的紀錄安全嗎？**
如果開啟了雲端備份（我 → 備份），就是安全的。在新 iPhone 上用同一個 Apple 帳號登入，並在第一個畫面選擇「還原」。沒有備份時，紀錄只存在手機上，所以請開啟備份或定期匯出。

**我不小心刪除了一筆紀錄。**
打開「我」→「垃圾桶」。紀錄會在那裡保留 30 天。

**我修改了一筆紀錄，想還原舊版本。**
打開該紀錄並捲動到「歷史」，點一下某個版本即可還原。

**家人需要安裝 App 嗎？**
不需要。他們會收到 PDF 格式的每月報告，或一個可在任何瀏覽器中開啟的私密連結。

**我的備註會出現在報告裡嗎？**
只有在分享前開啟「包含我的私密備註」時才會出現。

**如何取消 Pro？**
iPhone 設定 → 您的名稱 → 訂閱項目 → Kinledger。取消後，紀錄和匯出功能仍可使用。

**我可以匯出所有資料嗎？**
我 → 匯出我的所有資料：一份試算表和所有收據照片，隨時免費。

## 聯絡我們

請在 [github.com/BaturinIgor/Kinledger/issues](https://github.com/BaturinIgor/Kinledger/issues) 提出問題。我們會在兩個工作天內回覆。
