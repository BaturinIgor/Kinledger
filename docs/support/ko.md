# Kinledger 도움말

## 자주 묻는 질문

**iPhone을 잃어버려도 기록은 안전한가요?**
클라우드 백업이 켜져 있다면 안전합니다(나 → 백업). 새 iPhone에서 같은 Apple 계정으로 로그인하고 첫 화면에서 ‘복원’을 선택하세요. 백업이 없으면 기록은 iPhone에만 있으므로 백업을 켜거나 정기적으로 내보내세요.

**실수로 기록을 삭제했어요.**
나 → 휴지통을 여세요. 기록은 30일 동안 보관됩니다.

**기록을 수정했는데 이전 버전으로 되돌리고 싶어요.**
기록을 열고 ‘내역’까지 스크롤한 다음 되돌릴 버전을 탭하세요.

**가족도 앱이 필요한가요?**
아니요. 월간 보고서를 PDF나, 어떤 브라우저에서든 열리는 비공개 링크로 받습니다.

**메모도 보고서에 들어가나요?**
공유하기 전에 ‘내 비공개 메모 포함’을 켠 경우에만 들어갑니다.

**Pro는 어떻게 해지하나요?**
iPhone 설정 → 내 이름 → 구독 → Kinledger. 해지한 뒤에도 기록과 내보내기는 그대로 사용할 수 있습니다.

**내 데이터를 모두 가져갈 수 있나요?**
나 → 내 데이터 모두 내보내기: 스프레드시트와 모든 영수증 사진을 언제든지 무료로 내보낼 수 있습니다.
