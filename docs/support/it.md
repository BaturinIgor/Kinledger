# Aiuto Kinledger

## Domande frequenti

**Il mio diario è al sicuro se perdo l’iPhone?**
Sì, se il backup nel cloud è attivo (Io → Backup). Accedi con lo stesso account Apple sul nuovo iPhone e scegli Ripristina nella prima schermata. Senza backup le voci sono solo sull’iPhone: attivalo o esporta spesso.

**Ho eliminato una voce per sbaglio.**
Apri Io → Cestino. Le voci restano lì per 30 giorni.

**Ho modificato una voce e voglio la versione precedente.**
Apri la voce e scorri fino a Cronologia. Tocca una versione per ripristinarla.

**La mia famiglia ha bisogno dell’app?**
No. Riceve il resoconto mensile in PDF o con un link privato che si apre in qualsiasi browser.

**Le mie note finiscono nel resoconto?**
Solo se attivi “Includi le mie note private” prima di condividere.

**Come disdico Pro?**
Impostazioni dell’iPhone → il tuo nome → Abbonamenti → Kinledger. Voci ed esportazioni restano disponibili dopo la disdetta.

**Posso portare via tutti i miei dati?**
Io → Esporta tutti i miei dati: un foglio di calcolo e tutte le foto delle ricevute, gratis in qualsiasi momento.
