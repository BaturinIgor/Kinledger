# Aide Kinledger

## Questions fréquentes

**Mon journal est-il en sécurité si je perds mon iPhone ?**
Oui, si la sauvegarde cloud est activée (Moi → Sauvegarde). Connectez-vous avec le même compte Apple sur le nouvel iPhone et choisissez Restaurer sur le premier écran. Sans sauvegarde, vos entrées ne sont que sur l’iPhone : activez-la ou exportez régulièrement.

**J’ai supprimé une entrée par erreur.**
Ouvrez Moi → Corbeille. Les entrées y restent 30 jours.

**J’ai modifié une entrée et je veux retrouver l’ancienne version.**
Ouvrez l’entrée et faites défiler jusqu’à Historique. Touchez une version pour la rétablir.

**Ma famille a-t-elle besoin de l’app ?**
Non. Elle reçoit le rapport mensuel en PDF ou via un lien privé qui s’ouvre dans n’importe quel navigateur.

**Mes notes figurent-elles dans le rapport ?**
Seulement si vous activez « Inclure mes notes privées » avant de partager.

**Comment résilier Pro ?**
Réglages de l’iPhone → votre nom → Abonnements → Kinledger. Vos entrées et exports restent disponibles après la résiliation.

**Puis-je récupérer toutes mes données ?**
Moi → Exporter toutes mes données : un tableau et toutes les photos de reçus, gratuitement, à tout moment.

## Contact

Ouvrez un ticket sur [github.com/BaturinIgor/Kinledger/issues](https://github.com/BaturinIgor/Kinledger/issues). Nous répondons sous deux jours ouvrés.
