# Kinledger 1.0 — макеты экранов

Восстановлено из кода последнего коммита версии 1.0. Каждый экран снят в светлой и тёмной теме (iPhone, en_US), файлы в `screens/`.

| # | Экран | Что показано |
|---|-------|--------------|
| 01 | Today | Главный экран с данными за месяц |
| 02 | Log | Журнал записей |
| 03 | Report | Отчёт (бесплатная версия) |
| 04 | Me | Профиль и настройки |
| 05 | Report — Pro | Отчёт с открытым Pro |
| 06 | Me — Pro | Профиль с активным Pro |
| 07 | Today — пусто | Пустое состояние без записей |
| 08 | Log — пусто | Пустой журнал |
| 09 | Report — пусто | Пустой отчёт |
| 10 | Onboarding — кто вы | Первый шаг онбординга |
| 11 | Onboarding — семья | Шаг добавления семьи |
| 12 | Ошибка хранилища | Экран проблемы с данными |
| 13 | Quick log | Быстрое добавление записи |
| 14 | Quick log — большая сумма | Ввод крупной суммы (проверка вёрстки) |
| 15 | Quick log — редактирование | Редактирование существующей записи |
| 16 | Entry | Карточка записи |
| 17 | Paywall | Экран покупки Pro |
| 18 | Tax export | Экспорт для налоговой |
| 19 | Trash | Корзина с удалённой записью |
| 20 | Add person | Добавление получателя |
| 21 | Restore backup | Восстановление из резервной копии |
| 22 | Delete account | Удаление аккаунта |
